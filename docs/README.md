# Docs

This folder contains the non-root Markdown source for planning, architecture, development, and retained legacy material.

## Structure

- `architecture/`: implementation architecture, coding standards, and frontend styling rules
- `planning/`: core product spec and user stories
- `development/`: local environment and startup documentation
- `legacy/`: older source material retained for traceability, not for active backlog work

## Working Order

1. Read `planning/project_spec_v4-1.md` for system rules and product scope.
2. Read `planning/project_management_user_stories.md` for acceptance criteria.
3. Read `architecture/IMPLEMENTATION_ARCHITECTURE.md`, `architecture/CODING_STANDARDS.md`, and `architecture/FRONTEND_STYLE_GUIDE.md` before implementation.
4. Use `issues/` as the execution backlog.
