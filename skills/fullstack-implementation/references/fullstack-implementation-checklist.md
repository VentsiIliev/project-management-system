# Fullstack Implementation Checklist

1. Confirm the issue and acceptance criteria before editing files.
2. Read `IMPLEMENTATION_ARCHITECTURE.md` first.
3. Identify backend owner module and frontend owner feature.
4. Define the contract boundary before writing UI code.
5. Implement backend invariants before optimistic frontend behavior.
6. Keep serializers, views, pages, and components thin.
7. Add tests on both sides when the slice changes behavior across layers.
8. Record blockers or deferred follow-ups in the relevant issue file if the story is underspecified.
