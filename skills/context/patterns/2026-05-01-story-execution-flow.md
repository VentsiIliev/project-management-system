# Story Execution Flow

## Scope

- Area: delivery workflow
- Applies to: backlog stories that need planning, implementation, and validation

## Use This When

- A story is approved for execution and needs a clean implementation path.

## Do Not Use This When

- The story is still ambiguous enough that review findings or spec clarification should happen first.

## Why

- The repo is planning-heavy. Execution quality depends on keeping the transition from issue to code explicit and repeatable.

- `issues/stories/`
- `IMPLEMENTATION_ARCHITECTURE.md`
