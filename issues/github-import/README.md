# GitHub Issue Import Payloads

This folder contains the prepared issue payloads for `VentsiIliev/project-management-system`.

## Files

- `issue-payloads.json`: titles, bodies, and local source references for the epic and user-story issues.

## Current Blocker

The installed GitHub integration can read the target repository but cannot create issues there. Issue creation returned `403 Resource not accessible by integration` on May 1, 2026.

Once write access is enabled, these payloads can be used to create the backlog issues directly.
